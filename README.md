# bible_reading_tracker_base
A python script that tells me each daywhich Psalm, Proverb, and Canon Book I read based on today's date.

## What it does
- Calculates the daily Psalm by cycling through Psalms 1-150 using day-of-year
- Calculates the daily Proverb by cycling through Psalms 1-31 using day-of-year
- Selects the Canon Bookbased on the day of the month (first half vs. second half)

## What I learned buidling it
- Working with Python's 'datetime' module ('date.today()', timetuple()')
- Using modulo ('%') to cylce numbers within a fixed range
- Dictionaries and tuple unpacking
- The difference between day-of-month and day -of-year, and choosing the right one for each calculation
